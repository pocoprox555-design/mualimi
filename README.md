# معلمي 3

منصة تعلم عربية للسادس الإعدادي العراقي، مبنية حول الكتب المدرسية نفسها لا حول إجابات عامة غير موثقة.

## الفكرة

- محادثة تعليمية عربية مهيأة لرحمة: السادس الإعدادي في **مسار التعليم الديني**؛ يُعزل بحث المحادثة عن كتب الأدبي.
- **استرجاع محلي قبل كل رد** من 21 كتابًا و2,342 صفحة، مع كتالوج كامل ومصدر قابل للفتح ورقم مطبوع حين تم التحقق منه.
- فهرس `schemaVersion: 3` يعتمد postings من كامل نص الصفحة، ووزن ندرة الكلمات، ووصف الفهرس للتنقل في الصفحات المصورة.
- مكتبة كتب، بحث مباشر، اختبارات تفاعلية، خطة امتحانات، ومحادثات محفوظة على الجهاز.
- مفتاح الذكاء اختياري من الخادم، ويمكن للمستخدم الخاص حفظ مفتاحه على جهازه فقط من الإعدادات.
- تغيير المفتاح الدائم: Render → Environment → `AI_API_KEY` ثم Save/Deploy.
- يوجد في إعدادات التطبيق حقل واحد واضح للمفتاح، ويحفظه هذا الجهاز فقط.

## التشغيل

```bash
npm run verify                 # بناء الفهرس واختبار كل الطبقات
npm run import-deni            # استيراد كتب التعليم الديني الرسمية من pdf-sources
npm start                      # http://localhost:3000
```

بصفر اعتماديات تشغيلية — لا `npm install` مطلوب.

## مسار الإجابة

- استخراج نية السؤال ورقم الصفحة والكتاب محليا؛ سؤال «ما المواد؟» يمر عبر كتالوج الكتب الكامل لا عبر بحث كلمات عشوائي.
- الكتالوج الكامل للمواد والكتب يُرسل للنموذج في كل طلب، والنموذج وحده المتحكم الذي يفهم النية: جرد كامل إن كان السؤال جردا، وشرح من المصادر إن كان شرحا.
- بحث مقلوب سريع من كامل النص ثم قراءة النص الكامل للصفحات الأفضل فقط، مع إبراز المقاطع التي تطابق السؤال.
- في المحادثة يُستخدم مسار «ديني» وحده؛ لا تُخلط كتب السادس الأدبي بمصادر رحمة، ولا يُفترض أن مادة جدولها مطابقة تمامًا لاسم كتاب مختلف.
- إرسال سياق موسوم إلى النموذج: نص PDF للاستشهاد، ووصف الفهرس للتنقل فقط، مع منع اختراع أرقام الصفحات.
- النموذج الخارجي هو وحده من يصوغ الرد ويفهم المقصود؛ عند غياب مفتاح الذكاء أو تعطل الخدمة يظهر خطأ اتصال ولا تُعرض إجابة محلية جاهزة.
- بث حي بمهلة حقيقية، وإعادة محاولة قبل وصول أول رمز فقط حتى لا تتكرر الإجابة.
- حماية المفتاح، حد استخدام بسيط، وحدود لحجم الرسائل والصور.

## دقة المكتبة

- جميع الكتب الـ21 وصفحاتها الـ2,342 مرتبطة بملفات `pdf-books` ويمكن فتحها عبر `GET /api/page`.
- المتاح حاليًا 2,247 صفحة بنص قابل للبحث، و95 صفحة مصورة أو ذات تفريغ غير موثوق لا تُستشهد حرفيًا حتى التحقق منها.
- أُضيفت الكتب الرسمية التسعة التي عُثر عليها لمسار التعليم الديني (886 صفحة؛ 824 نصية بعد OCR لـ30 صفحة). كتاب الحنفي ملحق مصوّر بلا نص موثوق؛ المسار الافتراضي للفقه هو الشافعي كما يظهر في الجدول.
- المطابقة جزئية لكتاب «مباحث القراءات القرآنية» مقابل القرآن وعلومه، وللنحو والبلاغة مقابل العربية. لا تتوفر ملفات سادس رسمية للرواية أو أصول الفقه أو الجغرافية؛ ولا تُقدَّم مواد الأدبي بديلًا عنها. التفاصيل في `curriculum-library/reports/deni-sixth-books-report.md`.
- ملفات `outlines` تغطي كل الصفحات، لكنها خريطة وصفية للتنقل وليست بديلًا عن نص PDF أو OCR. أرقام الصفحات الفيزيائية تُعرض باعتبارها «صفحة PDF» حين لم يتحقق الرقم المطبوع.
- رفع دقة الصفحات المصورة نهائيا يتطلب OCR مسبقا أو تمرير صورة الصفحة إلى نموذج يدعم الرؤية؛ الخادم لا يدّعي أن الملخص وحده يساوي محتوى PDF.

## النشر (Render)

انظر `AGENTS.md`. اضبط `AI_MODEL=mimo-v2.6-flash` و`AI_API_KEY` صالحا في Render؛ يقبل التطبيق الاسم القديم ويحوّله تلقائيا.

> إذا ظهر مفتاح API في محادثة أو سجل، ألغِه من المزود وأنشئ مفتاحا جديدا.
