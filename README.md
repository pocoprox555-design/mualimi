# معلمي — معلمك الخاص للسادس الإعدادي

> تطبيق خاص للطالبة **رحمة** — مسار **التعليم الديني** للسادس الإعدادي العراقي. معلم خاص ذكي يفهم النية بنفسه كإنسان، يعرف المنهج **صفحة صفحة** (21 كتاب / 2342 صفحة)، ويشرح أي صفحة تُطلب فوراً بلا أعذار.

- **الرابط:** https://mualimi.onrender.com — **المستودع:** https://github.com/pocoprox555-design/mualimi — **الفرع:** `main`
- **النموذج الافتراضي:** `mimo-v2.6-flash` عبر `https://opencode.ai/zen/go/v1` — يمكن تغييره من Render بلا كود
- **التشغيل:** `Node.js >=22.3.0` — خادم واحد `server.mjs` — صفر اعتماديات تشغيل ثقيلة

---

## هوية التطبيق — اقرأ هذا أولاً قبل أي تعديل

**معلمي ليس بوت أسئلة عامة.** هو:

1. **معلم خاص لرحمة وحدها** — يخاطبها بصيغة المؤنث، بلمسة عراقية دافئة، كأم ثانية. يعرف مسارها (ديني) ويستخدم كتبه أولاً، لكنه يجيب عن أي مادة بذكاء بلا رفض غبي.
2. **مطّلع على المنهج كاملاً حرفياً** — كل صفحة لها `fullText` مستخرج نصاً في `curriculum-library/pdf-books/*.json` (مثال: رياضيات ديني 80 صفحة، فقه شافعي 106، حديث 159…). السيرفر يقرأ منها مباشرة، فلا يصح أن يقول "ما عندي وصول" أو "حطي نص الصفحة". المكتبة 21 كتاباً / 2342 صفحة، **ومنهج رحمة منها 11 كتاباً / 1281 صفحة** (المسار الديني). كتب الأدبي السبعة خارج مسارها عمداً: تُسقط من السياق ومن بطاقات المصادر.
3. **يفهم النية بنفسه (LLM-only)** — لا توجد قوائم كلمات مفتاحية في الكود. النموذج نفسه يصنف: `تحية وديّة → conversation` / `سؤال منهجي/صفحة → curriculum` / `سؤال عن الكتب → catalog` / `خارجي تماماً → external`. أي `if (text.includes("كيفك|مرحبا"))` داخل السيرفر هو تخريب. (الاستثناء الوحيد: عدد أسئلة الاختبار ورقم الصفحة — أرقام لا نيّة.)
4. **يشرح صفحات متعددة معاً** — "صفحة 22 من الرياضيات و 42 من الفقه" تُجلب متوازياً بـ `Promise.all` ويُشرح كل كتاب بعنوانه. لا يختزل إلى صفحة واحدة.
5. **لا يخترع، ويقول «لم أتحقق» بدل أن يملأ** — هذه ليست أدباً بل قاعدة مُنفَّذة في الكود لا في الوعد.
6. **واجهة فاخرة هادئة 60fps** — ترابية (`paper #f4f2ed` + `teal #287e78` + `gold #c9954a` + `deep #0f2d38`)، خط `Tajawal 400/700/800`، جوال احترافي: `mobile-nav` ثابت، `sidebar` من اليمين (RTL) مع `overlay` وقفل `scroll` وإغلاق بـ `Esc`، كل الأزرار `44px`، لا نيون بنفسجي.

**ما ليس من هوية التطبيق:** لا صفحات "خطتي/الاختبارات الوهمية" الزائدة (حُذفت في v5 وبقي `التعلم + جلساتي` فقط)، لا `Rate Limit` على رحمة (التطبيق خاص)، لا إضافات مدفوعة إلا مفتاح الذكاء نفسه.

## قواعد الصدق — مُنفَّذة في الكود (v6)

هذه القواعد ليست نصاً في البرومبت فقط؛ لكل واحدة موضع في الكود يُنفّذها:

| القاعدة | التنفيذ |
|---|---|
| **لا آية ولا حديث ولا نص مدرسي حرفي إلا من المقتطف** | قاعدة عليا في `systemPrompt` + ممنوع سرد سورة/رقم آية/راوٍ من الذاكرة |
| **طلب نص ديني بعينه ولم يرد ⇒ «النسخة الرقمية لا تُظهره كاملاً»** | قاعدة صريحة تمنع الآية المقاربة والحروف المبتورة و«﴿…﴾» الفارغة |
| **صفحة طلبتها ولم تُفتح ⇒ لا يُوصف محتواها** | `pageGate` في `handleChat`: تُحذف نتائج البحث العام من الـprompt، وتُسقط بطاقات المصادر، وتُوضع قاعدة «امتناع» صريحة |
| **صفحة بلا نص سليم + نموذج بلا رؤية ⇒ لا إجابة من ذاكرة** | `sendImageToVision` يمرر `supportsVision(model)` إلى فتح الصفحات، فلا يُحسب دليل بصري لا يُرسل |
| **«صفحة ٢٢» بلا مادة ⇒ سؤال توضيح، لا كتاب عشوائي** | `ambiguousPage`: لا `resolveBook` ولا `books[0]` ولا بطاقة مصدر |
| **مادة لها كتابان (اللغة العربية ١ و٢) ⇒ توضيح لا فتح جزء** | `exactSubject` في حلّ الصفحة: تطابق تام مع أكثر من كتاب ⇒ سؤال، و«النحو» لا يُنتقى |
| **اسم المادة يغلب كلمةً في عنوان كتاب آخر** | `guessedBook`: مطابقة اسم المادة +1، والكلمة العرضية في العنوان −0.6، ومصطلح يميّز كتاباً واحداً +1.2 |
| **لا كتاب ولا مادة مخترعة** | كتالوج المسار يُحمَّل **دائماً** في الطلب الدراسي، وقاعدة «أي كتاب لم يرد هنا ممنوع ذكره» |
| **لا `[S1]` ولا `[O1]` في نص الطالبة** | `citationStreamFilter` يحذف كل معرّف بين قوسين أثناء البث؛ مخطط الكتاب لم يعد بطاقة |
| **لا بطاقات بلا رقم صفحة** | `sourceCards` في الواجهة ترفضها، و`MAX_CITED_SOURCES=4` في السيرفر |
| **لا رسائل تقنية على الشاشة** | `step()` يبثّ عنواناً قصيراً فقط؛ التفاصيل في سجل الخادم |
| **لا طلب من رحمة كتابة نص الصفحة أو الصورة** | صيغة `VISION_NOT_SUPPORTED` والتعليمات صريحة بالمنع |

## كيف يعمل — مسار الإجابة الحقيقي

```
رحمة تكتب → [رقم صفحة في السؤال؟ → خطة مباشرة بلا مخطط] 
            → [غير ذلك: استطلاع بحث محلي (بلا PDF) → تخطيط النية إن لم تكفِ الأدلة]
                                          → conversation؟ → رد ودي بلا بحث ولا مصادر
                                          → curriculum → مصادر + كتالوج المسار + (مخطط)
                                          → بوابة الصدق: إمّا صفحة مفتوحة، وإمّا قاعدة امتناع
                                          → البرومبت: قواعد منع الاختلاق + الصفحات + كتالوج المسار + صور
                                          → streamCompletion (SSE) → ترشيح رموز الإحالة → رحمة ترى الكتابة حيّة
```

- **رقم الصفحة = معطى لا نيّة:** `planDirect()` يبني الخطة فوراً فيوفّر حتى ١٤ ثانية انتظاراً، ولا يدخل بحثٌ عام يُفسد جواب صفحة واحدة.
- **الصفحة المطلوبة وحدها في الـprompt:** لا يُحقن بحث عام (٣٦ ألف حرف) مع طلب صفحة، فيتضاعف زمن أول حرف ويأتي الجواب من صفحة أخرى.
- **التحية:** `intent=conversation` ⇒ رد ودي بلا بحث ولا مصادر، وخطوات البحث تُعرض فقط حين يثبت أن الطلب دراسي.
- **الصور المرفوعة:** إن كان النموذج **لا** يدعم `vision` تُخفى أدوات الإرفاق كلّها بدل حفظ صورة لا تُقرأ (`publicConfig().supportsVision`). وإن دعمها، تُقرأ الصفحة المصوّرة وتُذكر «صورة صفحة قُرئت بصريًا».
- **الاختبار التفاعلي:** `quizInstruction()` تُلزم النموذج بكتلة ```quiz بعدد الأسئلة الذي طلبته رحمة، وجولة إصلاح واحدة إن أخرج نصاً بدل البطاقة.

## طبقات المنهج — لا تلمس بلا فهم

| الطبقة | ما هي | لا تلمس؟ |
|---|---|---|
| `pdf-sources/*.pdf` | **مصدر الحقيقة** — 21 PDF رسمي | ⛔ لا تحذف نهائياً |
| `pdf-books/<id>.json` | صفحة بصفحة: `fullText`, `title`, `summary`, `pageType`, `printedPage` | تعديله لا يصل للتشغيل إلا عبر الجسر التالي |
| `pdf-index.json` | مجمّع من `pdf-books` | يُبنى بـ `npm run rebuild-pdf-index` |
| `search-index.json` | **مصدر الحقيقة وقت التشغيل** — فهرس مقلوب + نصوص | يُبنى بـ `npm run build-index` |
| `outlines/<id>.md` | خريطة وصفية للتنقل فقط | ليست نصاً للاقتباس |
| `enrichment/<id>.json` | تغذية منظمة (glossary/figures/…) | 20/21 مكتمل |

**التسلسل الإلزامي:** `pdf-books` → `rebuild-pdf-index` → `build-index` → `search-index.json` → `npm test` → `npm run gate`. تشغيل `build-index` مع `import-deni` معاً يفسد الفهرس.

الإحصاء الحقيقي: **2342 صفحة**، منها **2266 بـ fullText صالح (~96.8%)**، و45 صفحة من `fiqh-hanafi` بلا طبقة نص أصلاً (نص متجهي).

## التشغيل المحلي

```bash
npm ci
npm run verify   # rebuild-pdf-index + build-index + gate + test (81/81)
npm run smoke    # دخان: سيرفر حقيقي + مزود وهمي (26 فحصاً)
npm start        # http://localhost:3000
```

يتطلب `curriculum-library/pdf-sources` و`pdf-books` للتحقق. `npm run verify` يفشل بلا ملفات المنهج — هذا مقصود.

`npm run smoke` يشغّل `server.mjs` فعلاً أمام مزود ذكاء وهمي ويتحقق من: تحية بلا مصادر · صفحة بلا مخطط نية وبلا بحث عام · بوابة الامتناع عند تعذّر فتح صفحة · توضيح عند «صفحة ٢٢» بلا مادة · كتالوج حقيقي · اختبار تفاعلي بالعدد المطلوب · صفحتان معاً · لا `image_url` لنموذج بلا رؤية.

## النشر — Render (مجاني)

انظر `AGENTS.md` للتفصيل. الخلاصة:

```bash
git add -A
git -c user.name='Mualimi' -c user.email='deploy@mualimi.local' commit -m "وصف التعديل"
git push   # Render يبني تلقائياً 2-3 دقائق
```

**المتغيرات في Render → Environment:**

| المفتاح | القيمة |
|---|---|
| `AI_API_KEY` | مفتاحك (`b64:` مدعوم) |
| `AI_ENDPOINT` | `https://opencode.ai/zen/go/v1` |
| `AI_MODEL` | `mimo-v2.6-flash` — غيّره لأي نموذج من نفس المزود بلا كود (مثلاً `deepseek-v4-flash-vision-exp` للصور) |
| `AI_CONTEXT_WINDOW` | `1000000` |
| `AI_MAX_OUTPUT_TOKENS` | `8000` (السقف 16000) |

الطبقة المجانية تنام بعد 15 دقيقة خمول (~50 ثانية صحوة).

## شروط صارمة — تخريب التطبيق يبدأ من هنا

1. **لا تضف قائمة كلمات للنية.** `if (msg.includes("كيفك|مرحبا|شلونك"))` ممنوع. الفهم LLM فقط عبر `PLAN_INSTRUCTIONS` + `systemPrompt`.
2. **لا تطلب من رحمة نص الصفحة أو نص الصورة.** النص في `pdf-books/fullText`. إن لم تجده اشرح من خبرتك أو قل «لم أتحقق»، ولا تعتذر بـ "ما عندي وصول".
3. **لا تغيّر `curriculum-library` ثم ترفع بلا `verify`.** ستنشر فهرساً قديماً.
4. **لا تضف `Rate Limit` أو قيود غبية.** التطبيق خاص.
5. **لا تضع `AI_API_KEY` في الكود.** فقط `Render Environment` أو `local .env` (محجوب بـ `.gitignore`/`.dockerignore`).
6. **لا ترفع `.env`.** ولا تغيّر `Dockerfile` لنسخ أسرار.
7. **لا ترجع صفحة "خطتي" أو واجهات زائدة** بلا طلب صريح — v5 ثنائية فقط (تعلم + جلساتي).
8. **الصور:** الخادم يعلن `supportsVision` في `/api/config`، والواجهة تُخفي أدوات الإرفاق إن كان النموذج بلا رؤية. لا تُرجِع `@attachButton` ظاهراً مع نموذج لا يقرأ الصور.
9. **لا تُضعِف `pageGate`.** هو ما يمنع «شرح صفحة من كتاب آخر» و«آية مختلقة». أي تعديل يفتح صفحات البحث العام مع طلب صفحة محددة يعيد P0.
10. **اقرأ `MEMORY.md` قبل أي تعديل** — فيه كل قرار وتخريب سابق وكيف أُصلح.
