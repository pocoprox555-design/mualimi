# معلمي — معلمك الخاص للسادس الإعدادي

> تطبيق خاص للطالبة **رحمة** — مسار **التعليم الديني** للسادس الإعدادي العراقي. معلم خاص ذكي يفهم النية، ويشرح من الأدلة التي يسترجعها من المكتبة، ويصرّح بوضوح عندما يتعذر التحقق من صفحة.

- **الرابط:** https://mualimi.onrender.com — **المستودع:** https://github.com/pocoprox555-design/mualimi — **الفرع:** `main`
- **النموذج المسجّل:** `deepseek-v4.1-flash` عبر `https://opencode.ai/zen/go/v1` — لا يعمل التطبيق إلا بنموذج مسجّل في `lib/config.mjs`؛ أي قيمة أخرى في `AI_MODEL` (منها النماذج القديمة `mimo-*`) تُتجاهَل ويُستعمل المسجّل مع إشعار.
- **التشغيل:** `Node.js >=22.3.0` — خادم واحد `server.mjs` — صفر اعتماديات تشغيل ثقيلة

---

## هوية التطبيق — اقرأ هذا أولاً قبل أي تعديل

**معلمي ليس بوت أسئلة عامة.** هو:

1. **معلم خاص لرحمة** — يخاطبها بصيغة المؤنث وبعربية واضحة وهادئة.
2. **وسيط رفيع إلى المكتبة** — النموذج يختار بنفسه الكتب والأدوات وتسلسل القراءة. لا يختار الخادم مادة أو كتاباً مسبقاً. المكتبة تضم 21 كتاباً و2342 صفحة؛ قد تكون بعض الصفحات بلا طبقة نص أو تحمل نصاً متضرراً.
3. **يفهم النية بنفسه** — لا يوجد توجيه سؤال بكلمات مفتاحية أو مسار تحية/منهج ثابت. سجل الحوار كامل يصل للنموذج ما دامت نافذة السياق تسمح، ونتائج الأدوات القديمة قد تُعلّم بوضوح بأنها أزيلت من السياق ويمكن جلبها مجدداً.
4. **أدوات قابلة للتصفح** — البحث يعيد صفحات مرشحة كاملة على دفعات معلنة؛ قراءة الصفحة والنطاق والفهرس لا تختزل نص المصدر بصمت.
5. **صدق المصدر** — الأداة تميّز النص المستخرج عن وصف الفهرس، وتذكر رقم الصفحة المطبوع ورقم PDF الفيزيائي كلّاً على حدة. النموذج يصرّح عندما لا يتوفر الدليل.
6. **واجهة محادثة أولاً** — لوحة فحمية ورمادية كلاسيكية بلمسات معدنية هادئة، متناسقة في الوضعين النهاري والليلي، تخطيط RTL واسع ومريح للجوال، سجل الجلسات في قائمة جانبية، اختصار ثابت لمحادثة جديدة، وإعدادات تقتصر على مفتاح الاتصال. لا تعرض الواجهة اسم النموذج أو المزوّد، واسم الطالبة ثابت: رحمة.

**ما ليس من هوية التطبيق:** لا صفحات "خطتي/الاختبارات الوهمية" الزائدة (حُذفت في v5 وبقي `التعلم + جلساتي` فقط)، لا `Rate Limit` على رحمة (التطبيق خاص)، لا إضافات مدفوعة إلا مفتاح الذكاء نفسه.

## عقد الوسيط

- `lib/agent.mjs` لا يفسر نية السؤال ولا يقرر أداة أو كتاباً. ينفّذ نداءات النموذج حتى يجيب، أو يعيد فشل الأداة إليه، أو يعلن سبب التوقف.
- `lib/tools.mjs` يقدّم: `list_books`, `get_book`, `search_books`, `read_page`, `read_pdf_page`, `read_pages_range`, `get_outline`, `get_page_neighbors`.
- البحث يعيد نص الصفحة كاملاً في دفعات مرتبة ترتيباً ثابتاً لا ترتيب صلة؛ `nextOffset` يعلن استمرار النتائج. نطاق الصفحات والفهارس لها دفعات يمكن استكمالها.
- `read_page` يميّز النص المستخرج والوصف غير الحرفي وحالة التلف. `read_pdf_page` يذكر إن فُتح الأصل فعلاً، ويصرّح بفشل الرسم أو غياب الصورة.
- page number fields distinguish `printedPage` (printed in the book) from `physicalPage` (PDF index). Do not assume they match.
- لا توجد بوابة لاحقة تعيد صياغة رد النموذج أو تحذف ادعاءاته. رسائل الفشل تخص التشغيل فقط؛ نتيجة الأداة هي المسار الذي يتعلم منه النموذج أن القراءة أخفقت.
- عند طول السياق، نتائج الأدوات القديمة التي أزيلت تستبدل بعلامة توضح اسم الأداة وحجم النص، ليتمكن النموذج من استدعائها مجدداً. إذا لم تكفِ الميزانية بعد ذلك، يظهر خطأ سياق صريح.

## كيف يعمل — مسار الطلب

```
رحمة تكتب + سجل الجلسة → server.mjs
  → system prompt قصير + الأدوات + السجل الكامل
  → النموذج يقرر: يجيب / يبحث / يقرأ صفحة أو نطاقاً / يفتح PDF أو الفهرس
  → الخادم يعيد نتيجة الأداة كاملة أو يمرر الخطأ للنموذج
  → النموذج يقرر ما إذا كان يحتاج أداة أخرى أو اكتفى
  → إكمال تلقائي إذا انتهى حد خرج النموذج، مع استمرار تدفق الرد
  → SSE إلى الواجهة؛ فشل حقيقي = رمز/رسالة واضحة وزر إعادة
```

- **الصور:** `lib/config.mjs` يحدد دعم الرؤية؛ كل الصور المرفقة الصالحة تُرسل، وتُتاح أداة PDF لقراءة الصفحة الأصلية. إذا تعذر إنشاء صورة أو لم يُرسلها النموذج، تظهر حالة ذلك في نتيجة الأداة.
- **المدخلات الطويلة:** لا تُقص أسئلة أو ردود الجلسة برقم ثابت في الواجهة. يتخلص سياق الوكيل من نتائج أدوات قديمة فقط بعلامة صريحة، ويتيح إعادة جلبها.

## طبقات المنهج — لا تلمس بلا فهم

| الطبقة | ما هي | لا تلمس؟ |
|---|---|---|
| `pdf-sources/*.pdf` | **مصدر الحقيقة** — 21 PDF رسمي | ⛔ لا تحذف نهائياً |
| `pdf-books/<id>.json` | صفحة بصفحة: `fullText`, `title`, `summary`, `pageType`, `printedPage` | تعديله لا يصل للتشغيل إلا عبر الجسر التالي |
| `pdf-index.json` | مجمّع من `pdf-books` | يُبنى بـ `npm run rebuild-pdf-index` |
| `search-index.json` | **مصدر الحقيقة وقت التشغيل** — فهرس مقلوب + نصوص | يُبنى بـ `npm run build-index` |
| `outlines/<id>.md` | خريطة وصفية للتنقل فقط | ليست نصاً للاقتباس |
| `enrichment/<id>.json` | تغذية منظمة (glossary/figures/…) | 20/21 مكتمل |

**التسلسل الإلزامي:** `pdf-books` → `rebuild-pdf-index` → `build-index` → `search-index.json` → `npm run gate`. تشغيل `build-index` مع `import-deni` معاً يفسد الفهرس.

يعرض `/api/health` حالة صفحات الفهرس لحظياً (`clean-extracted-text` و`ocr-text` و`damaged-text` و`no-text`). لا تعني `fullTextPages` أو `searchablePages` أن كل صفحة صالحة للاقتباس؛ تُستخدم بوابة الصدق لمنع وصف صفحة بلا دليل موثوق.

## التشغيل المحلي

```bash
npm ci
npm run verify   # rebuild-pdf-index + build-index + build-shards + gate
npm start        # http://localhost:3000
```

يتطلب `curriculum-library/pdf-sources` و`pdf-books` للتحقق. `npm run verify` يفشل بلا ملفات المنهج — هذا مقصود.

## النشر — Render (مجاني)

انظر `AGENTS.md` للتفصيل. الخلاصة:

```bash
git add -A
git -c user.name='Mualimi' -c user.email='deploy@mualimi.local' commit -m "وصف التعديل"
git push   # Render يبني تلقائياً 2-3 دقائق
```

**إعدادات Render → Environment:**

| المفتاح | القيمة |
|---|---|
| `AI_ENDPOINT` | `https://opencode.ai/zen/go/v1` |
| `AI_MODEL` | `deepseek-v4.1-flash` — أي قيمة غير مسجّلة تُتجاهَل ويُستعمل المسجّل |
| `AI_SUPPORTS_VISION` | اختياري `true`/`false` لتجاوز كشف دعم الصور |
| `AI_CONTEXT_WINDOW` | `1000000` (نافذة DeepSeek-V4.1-Flash المعلنة رسمياً) |
| `AI_MAX_OUTPUT_TOKENS` | `8000` افتراضياً في إعداد النشر؛ السقف البرمجي `384000` (حد خرج DeepSeek V4.1 Flash) |

لا تضعي `AI_API_KEY` في Render: تدخل الطالبة المفتاح في الإعدادات، ويُرسل مع كل طلب عبر `X-AI-API-Key` فقط. الطبقة المجانية تنام بعد 15 دقيقة خمول (~50 ثانية صحوة).

## قواعد التعديل

1. لا تضف تصنيف نية أو اختيار كتاب أو بوابة صفحة في الخادم؛ اجعل القرار للنموذج عبر الأدوات.
2. لا تقص نص صفحة أو نتيجة بحث بصمت. للنتائج الطويلة استخدم `offset`/`nextOffset` وصرّح بحالة النص أو الملف.
3. أعد أخطاء الأدوات للنموذج كرسالة أداة، ولا تحوّل الخطأ إلى صفحة مفقودة أو جواب ثابت.
4. لا تضف حراساً تعدّل نص النموذج بعد توليده. افصل بين الدليل المستخرج والوصف الفهرسي وسجّل المصدر.
5. لا تخزّن `AI_API_KEY` في الخادم أو Render؛ يمر المفتاح من واجهة المستخدم في هيدر `X-AI-API-Key`.
6. عند تعديل `curriculum-library` أعد بناء الفهرس وفق التسلسل في قسم طبقات المنهج.
7. حافظ على واجهة التطبيق الحالية (التعلم + جلساتي) ما لم يطلب المستخدم تغييرها.
8. راجع `MEMORY.md` قبل أي تعديل، ولا تنشر دون طلب صريح.

## البنية الحالية (thin agent)

```
server.mjs              HTTP + SSE + system prompt قصير؛ لا يوجّه الأدوات ولا يعيد كتابة الجواب
lib/agent.mjs           حلقة أدوات مفتوحة، إكمال الرد، كشف التكرار، وإدارة نتائج الأدوات القديمة
lib/tools.mjs           قائمة الكتب، بيانات كتاب، بحث قابل للتصفح، صفحة/نطاق/PDF/فهرس/جوار
lib/provider.mjs        Chat Completions streaming + retry للأخطاء المؤقتة قبل أول خرج
lib/index.mjs           فهرس صفحاته مكتمل؛ نتائج البحث مرتبة ترتيباً ثابتاً وتصل كاملة على دفعات
lib/pdf-fallback.mjs    فتح PDF الأصلي، cache للمستندات ونصوص الصفحات، وصورة الصفحة عند الطلب
lib/outline.mjs         قراءة ملف outline الخام؛ أداة القراءة لا تحذف أو تعيد صياغة الأسطر
public/app.js           سجل جلسة كامل ضمن مساحة التخزين المتاحة، SSE، إعادة محاولة واضحة
public/index.html       تعلم + جلساتي؛ يستقبل كل النصوص والصور المختارة
curriculum-library/     PDFs والفهارس والكتب
```

لم تُشغّل الاختبارات في جولة إعادة التهيئة بناءً على طلب المستخدم.

> أي مفتاح ظهر في سجل → ألغِه من المزود فوراً.
