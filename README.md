# معلمي v2

مساعد دراسي عربي للسادس الإعدادي العراقي — بناء جديد من الصفر: سريع، بسيط، لا ينقطع.

## الفكرة

- محادثة عربية دافئة مع «المعلم» لطالبة اسمها رحما (أحيائي / تطبيقي / أدبي).
- **بحث تلقائي واحد** في الكتب المدرسية قبل كل رد (12 كتابًا، 1456 صفحة مفهرسة بعنوان وشرح مبسط لكل صفحة) + شواهد مصادر.
- اختبارات تفاعلية، مواعيد امتحانات، محادثات محفوظة على الجهاز.
- المزود (المفتاح + الرابط + النموذج) يُضبط من داخل التطبيق ⚙.

## التشغيل

```bash
npm test
node scripts/build-index.mjs  # توليد الفهرس الخفيف (مرة واحدة)
node server.mjs                # http://localhost:3000
```

بصفر اعتماديات — لا `npm install` مطلوب.

## لماذا لا يعلق ولا ينقطع؟

- لا وكيل متعدد الجولات: استدعاء واحد للمزود مع سياق جاهز (الرد يبدأ خلال ثوانٍ).
- إعادة محاولة تلقائية ×3 عند الانقطاع + زر إعادة يدوي + إيقاف.
- نبض heartbeat يمنع قطع البروكسيات، وبديل JSON عادي إن فشل البث.
- تخزين محلي محدود (30 محادثة) حتى لا يمتلئ المتصفح.
- إيقاظ تدريجي للخادم مع حالة اتصال واضحة.

## النشر (Render)

انظر `AGENTS.md`. المهم: اضبط `AI_MODEL=MiMo-V2.6-Flash` (بالحالة الأصلية) و`AI_API_KEY` صالحًا.
