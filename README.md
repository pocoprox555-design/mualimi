# معلمي

مساعد تعليمي عربي للسادس الإعدادي، مع محادثة متدفقة ومكتبة منهج محلية مفهرسة صفحةً صفحة.

## المتطلبات

- Node.js `>=22.3.0`
- npm
- مفتاح API لنقطة نهاية متوافقة مع OpenAI Chat Completions

## الإعداد

```bash
npm ci
cp .env.example .env
npm run build
npm start
```

متغيرات الخادم:

- `AI_API_KEY`: مفتاح النموذج، ولا يصل إلى المتصفح.
- `AI_MODEL`: اسم النموذج. الافتراضي `mimo-v2.5`. **يجب** أن يدعم النموذج
  استدعاء الأدوات (tool calling) وقراءة الصور (`image_url`)، لأن الوكيل يحوّل
  صفحات PDF المصوّرة إلى صور ويرسلها للنموذج. نماذج بلا رؤية (مثل deepseek)
  ستفشل عند فتح الصفحات المصوّرة.
- `AI_ENDPOINT`: نقطة نهاية Chat Completions المتوافقة مع OpenAI.
- `AI_CONTEXT_WINDOW` / `AI_MAX_OUTPUT_TOKENS`: حدود السياق والإخراج.
- `PORT`: منفذ الإنتاج؛ تضبطه CloudRun تلقائيًا.
- `CURRICULUM_ADMIN_TOKEN`: رمز سري مطلوب لرفع/حذف الكتب في الإنتاج.

## مكتبة المنهج

المكتبة المضمّنة موجودة في `curriculum-library/`، والمرجع النشط حالياً هو PDF لكل كتاب. لكل كتاب PDF:

- `manifest.json`: بيانات الكتاب والطبعة والصفحات والبصمات.
- `source/original.txt`: نسخة المصدر للتدقيق.
- `pages/NNNN.txt`: ملف UTF-8 مستقل لكل صفحة.
- `index/search-index.json`: فهرس بحث عربي مولّد.
- `pdf-sources/`: ملفات PDF الأصلية.
- `pdf-books/<book-id>.json`: فهرس مستقل لكل كتاب وصفحة، مع الملخص والغرض ونوع الصفحة.
- `pdf-index.json`: فهرس عام سريع.

تم نقل ملفات TXT السابقة إلى `curriculum-library/legacy-text-sources/` كنسخة احتياطية فقط، ولا يستخدمها الوكيل كمرجع نشط.

الأوامر:

```bash
npm run curriculum:import -- "D:/path/book.txt" --id book-id --title "اسم الكتاب" --subject "المادة" --year 2025
npm run curriculum:reindex
npm run curriculum:validate
npm test
```

واجهات القراءة:

- `GET /api/library/books`
- `GET /api/library/search?q=...&subject=...&bookId=...&limit=8`
- `GET /api/library/page?bookId=...&page=41&radius=1`

تجري `/api/chat` عملية بحث تلقائي داخل المكتبة قبل استدعاء النموذج، وتضع الصفحات المسترجعة في سياق منفصل مع اسم الكتاب والمادة والصفحة والأسطر. النص المرجعي يعامل كبيانات غير موثوقة من ناحية التعليمات لمنع حقن الأوامر عبر الكتب.

### كتب PDF والرؤية

ملفات PDF المدرسية المضمنة موجودة في `curriculum-library/pdf-sources/` (12 كتابًا
بعد إزالة النسخ المكررة). يبني الأمر التالي فهرساً لكل كتاب وصفحة:

```bash
npm run curriculum:pdf-index
```

الفهرس يستخرج نص كل صفحة ويحسم **الرقم المطبوع** لكل صفحة عبر ثلاث طبقات:
مطابقة الكلمات المفتاحية، ثم الرقم الافتتاحي بتسلسل متتابع مع جسْر الصفحات
الفارغة، ثم تصويت إزاحة ثابتة (مطبوع = فيزيائي + إزاحة). هذا يجعل
`locate_pdf_page` يترجم أرقام الصفحات التي تذكرها الطالبة إلى صفحات PDF الفعلية.

يبحث الوكيل في الفهرس أولاً، ثم يحوّل الصفحات المطلوبة إلى صور JPEG ويرسلها
إلى النموذج عند الحاجة. لا يُرسل ملف PDF كاملاً إلى النموذج، ولا تُرسل إلا
الصفحات التي يحددها الوكيل. البحث العربي يطبّع التشكيل ويصلح تشوهات OCR
الشائعة (مثل انقلاب «ال» إلى «امل») حتى تتطابق استعلامات الطالبة مع النص.

```bash

```

لا يحتاج أي من هذه الأوامر إلى تشغيل الخادم.

## النشر العام

المشروع مجهز كحاوية عبر `Dockerfile` ويستمع إلى متغير `PORT`، لذلك يناسب CloudBase CloudRun مع SSE. إعداد النشر المستهدف:

- النوع: Container
- الوصول: `PUBLIC`
- المنفذ: `3000`
- CPU: `0.5`
- الذاكرة: `1 GB`
- الحد الأدنى للنسخ: `1` لتقليل البداية الباردة
- الأسرار: `AI_API_KEY` و`CURRICULUM_ADMIN_TOKEN` كمتغيرات بيئة في الخدمة

لا يوجد `EnvId` مخمّن داخل المشروع. عند اكتمال المواد والتصميم يجب تسجيل الدخول إلى CloudBase، اختيار البيئة الفعلية، نشر الحاوية، ثم اختبار الرابط العام قبل تسليمه.

> قرص CloudRun غير مناسب للبيانات المتغيرة الدائمة. الكتب المضمّنة وقت بناء الصورة تعمل للقراءة. أما رفع كتب جديدة بعد النشر فسينقل لاحقًا إلى تخزين دائم قبل تفعيل الإدارة العامة.

## حقوق المحتوى

لا تستورد كتبًا من مرايا غير رسمية ما لم تملك حق استخدامها. ملف `curriculum-library/sources.json` للفهرسة والمتابعة فقط ولا يعني السماح بالتنزيل أو إعادة التوزيع.
